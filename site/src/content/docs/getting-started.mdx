ParaPDF needs React 19.3 or later. It ships a worker for pdfjs-dist 6.5.438
and loads matching fonts and decoders from that exact dependency.

## Show a PDF

```tsx
import { PdfDocument, PdfViewer } from "parapdf";

export function App() {
  return (
    <PdfDocument source="/manual.pdf">
      <PdfViewer style={{ height: "100vh" }} />
    </PdfDocument>
  );
}
```

<QuickStartExample client:visible />

- `PdfDocument` starts opening the document and renders its children at
  once. The viewer can show its first page without a Suspense boundary.
- `PdfViewer` is a viewport onto it, the scroll container. Give it a
  definite height, as above or through a flex or grid layout: it contains
  its own layout and does not grow with the document.
- In the browser, the first `PdfDocument` starts loading pdf.js and its
  worker. A plain PDF URL can download alongside them. WebKit skips this
  preload on the client. With server rendering, the HTML can start the PDF
  download before React runs. [Server rendering and preload behavior](/setup/server-rendering/)
- This works as it is with bundlers that emit files referenced with
  `new URL(…, import.meta.url)`, such as Vite, webpack, Rsbuild, and Next.js:
  see [Bundlers](/setup/bundlers/) for the others.

A source can also be `{ url, httpHeaders, withCredentials }` or `{ data }`
with the PDF's bytes: see [Sources](/reference/sources/).

## Add controls

`PdfDocument` provides a viewer to everything inside it. Read it with
`useViewer()` and its state with `useViewState()`:

```tsx
import { PdfDocument, PdfViewer, useViewer, useViewState } from "parapdf";

function PageNumber() {
  const viewer = useViewer();
  const { currentPage, pageCount } = useViewState();
  return (
    <span>
      <button type="button" onClick={() => viewer.previousPage()}>Previous</button>
      {currentPage + 1} / {pageCount}
      <button type="button" onClick={() => viewer.nextPage()}>Next</button>
    </span>
  );
}

export function App() {
  return (
    <PdfDocument source="/manual.pdf">
      <PageNumber />
      <PdfViewer style={{ height: "90vh" }} />
    </PdfDocument>
  );
}
```

`useViewState()` tracks the fields read during rendering and renders its
component again only when one of them changes: scrolling through a page
renders `PageNumber` once, when `currentPage` changes. The document's own
state, loading, errors, and password requests, is `useDocumentState()`'s:
see [State](/reference/state/).
