```bash
npm install parapdf
```

```tsx
import { PdfDocument, PdfViewer } from "parapdf";

export function App() {
  return (
    <PdfDocument source="/manual.pdf">
      <PdfViewer style={{ height: "100vh" }} />
    </PdfDocument>
  );
}
```

That is all the setup: ParaPDF ships pdf.js, its worker, and the files it
loads on demand, and your bundler serves them from your application's origin—no
`public/pdfjs/` folder, no `viewer.html`, and no `postMessage` bridge.

<CardGrid>
  <Card title="Your React UI, right on the page" icon="puzzle">
    Portal highlights, citations, review cards, and validation badges onto
    pages in PDF points with `PdfPageRect`. They follow zoom and rotation
    through CSS layout alone, without clipping at an `iframe` border or lagging
    behind `postMessage`.
  </Card>
  <Card title="React stays out of the hot path" icon="rocket">
    Scrolling and zooming commit no React state per frame. React renders only
    when the window of mounted pages or the current page changes, pixels stay in
    imperative canvases, and pages you come back to show the canvases they kept.
  </Card>
  <Card title="One document, many views & lifetimes" icon="open-book">
    A `PdfDocument` opens one worker and session for any number of `PdfViewer`s
    and `PdfThumbnails`, and `useViewer()` keeps scroll position, zoom, search,
    and edits across React unmounts, tabs, and `<Activity>`.
  </Card>
  <Card title="Typed hooks, zero viewer bloat" icon="pencil">
    Selectable tagged text, whole-document search, outline and link history,
    two-way AcroForm state, annotation editing, layers, attachments, printing,
    auth headers, and SSR—each loaded only when your app uses it.
  </Card>
</CardGrid>

ParaPDF is at 0.x: its API may change in any minor release until 1.0. See
[Why React, not an iframe](/why-react/) for side-by-side interactive examples,
the [changelog](https://github.com/yhay81/parapdf/blob/main/CHANGELOG.md) for
releases, and [Performance](/about/performance/) for the measurements behind
the design, losses included.
