```bash
npm install parapdf
```

```tsx
import { PdfDocument, PdfViewer } from "parapdf";

export function App() {
  return (
    <PdfDocument source="/manual.pdf">
      <PdfViewer style={{ height: "100vh" }} />
    </PdfDocument>
  );
}
```

ParaPDF ships pdf.js, its worker, and the files a document can load on demand.
Vite, webpack, Rsbuild, and Next.js emit those files with your application.
For other bundlers, serve a static copy. [Bundler setup](/setup/bundlers/)

<CardGrid>
  <Card title="Your React UI, right on the page" icon="puzzle">
    Portal highlights, citations, review cards, and validation badges onto
    pages in PDF points with `PdfPageRect`. They follow zoom and rotation
    through CSS layout alone, without clipping at an `iframe` border or lagging
    behind `postMessage`.
  </Card>
  <Card title="React stays out of the hot path" icon="rocket">
    The viewer mounts pages and draws their canvases directly. A page counter
    updates when the current page changes. Scrolling within that page needs no
    React update from the counter.
  </Card>
  <Card title="One document, many views & lifetimes" icon="open-book">
    Several panes can read different pages of one open document. Keep
    `PdfDocument` mounted while toggling its default `PdfViewer` to restore
    position, zoom, search, and edits when the viewport returns.
  </Card>
  <Card title="Choose your reading tools" icon="pencil">
    Text selection and PDF links work by default. Add whole-document search,
    form filling, annotation editing, or printing when your application needs them.
  </Card>
</CardGrid>

ParaPDF is at 0.x: its API may change in any minor release until 1.0. See
[Why React, not an iframe](/why-react/) for side-by-side interactive examples,
the [changelog](https://github.com/yhay81/parapdf/blob/main/CHANGELOG.md) for
releases, and [Performance](/about/performance/) for the measurements behind
the design, losses included.
