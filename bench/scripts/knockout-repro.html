Renders one page with pdf.js's display API (getDocument and PDFPageProxy.render) and times every drawImage call, on the main thread and, with pdf.js master's renderer worker, in that worker. Calls that read the canvas being rendered are the knockout backdrop copies in #compositeKnockoutSurface. Opened by hand, it renders once to warm up and then runs times, and prints the timings; for the case in the issue, open it with ?hwa=0&region=0,0,5000,3360 and again with &annotations=0 added.

Query parameters: lib, worker, and renderer (pdf.js scripts; renderer enables master's renderer worker), assets (the directory holding cmaps/ and standard_fonts/), file, page, hwa (1 or 0), scale (device pixels per PDF point), region (x,y,width,height in device pixels; the whole page when absent), annotations (1 or 0), probe (1 to time reading one pixel of the canvas right after each render), and runs.
